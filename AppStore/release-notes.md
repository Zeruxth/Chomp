The **App Store version** of Chomp: the same app, sandboxed and without ffmpeg, as it will ship on the Mac App Store. Most people want the [regular download](https://github.com/Zeruxth/Chomp/releases/latest) instead.

## What's different

- Saves to **Downloads/Chomped** by default. "Beside original" asks once per folder.
- Video and audio use Apple's own frameworks: MP4, MOV, M4A, compress, under 10 MB, half size, still frame, mute, 2× speed. WebM, MKV, GIF from video, MP3, OGG and FLAC aren't in this version.

## Install

1. Download **Chomp-AppStore.zip** below and unzip it.
2. Drag **Chomp.app** into Applications and open it. Quit the regular Chomp first, so they don't both answer the same drag.
3. First time only: this build isn't signed, so macOS stops it. Click **Done**, then **System Settings → Privacy & Security → Open Anyway**.
