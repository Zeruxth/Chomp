Chomp

Pixel pass

The mimic is already great pixel art. Everything around it (the wheel, the toast, the menu panel) is smooth macOS glass with rounded system text. This page shows what it looks like when the whole app lives in the chest's world, what to fix in the code, and how to get it onto your friends' Macs.

What already works

The core trick

Drag a file, tap ⇧ ⌘ or ⌃, drop on a slice. No Accessibility permission needed. That is the hard part and it's done.

The mimic

32×33 grid, a tight oak-and-gold palette, real frame animations (peek follows the hovered slice, bite on drop). Keep all of it.

Safe by default

Originals are never touched, outputs never overwrite, and every job has Show and Undo.

Voice

"Couldn't chew that", "Spat it out", "nevermind". The copy already has a character. Lean into it a bit more.

Try it

The wheel, pixelated

beach.heic

Hover a slice and the mimic's eyes follow it. Click and it bites, then the toast pops up. The middle cancels.

How it's drawn: the disc is painted pixel by pixel on a 220×220 grid and shown at 2×. Each pixel checks its angle and distance from the centre to decide which slice it belongs to. In Swift this is one Canvas loop, the same idea as the current Sector shape but filling a grid instead of a smooth path.

Text stays readable: the slice names use a pixel font because they're one short word ("WebP", "Zip"). The grey detail line under each name stays in a plain font, because "No EXIF / GPS" in pixels at 10pt is hard to read.

Gaps between slices are a fixed 4 pixels wide instead of a fixed angle, so they look the same whether there are 4 slices or 8.

Room to breathe: this version is about 15% bigger than today's wheel (440 vs 380 points), with more space between the hole and the slices and between each name and its detail line. In the app that means changing Geo.size, outer and inner in Wheel.swift. With 8 slices it's still the tightest mode, so the Wheel settings let people hide formats they never use.

Code review

Fix before friends use it

Blocker

Video, audio, WebP and AVIF need Homebrew's ffmpeg.Your friends won't have it, so half the wheel fails for them. The plan below fixes this without Homebrew and without a big download.

Blocker

macOS warns the first time someone opens it.build.sh signs with --sign -, which is free but not trusted by Apple. Without the paid Apple program this warning can't be removed, only made painless. See the shipping plan below.

Bug

Zip silently drops items from other folders.Converters.swift:548 keeps only items whose parent is the first item's folder. Drag files from two folders (say, from a search window) and some are missing from the zip with no warning.

UX

No progress or cancel on long jobs.Compressing a 2 GB video shows "Converting…" with no end in sight. ffmpeg can report progress (-progress pipe:1); show a pixel progress bar in the toast and add a Stop button.

Small

The toast always opens on the main screen.HUD.swift:30 uses NSScreen.main. With two monitors it can pop up on the screen you're not looking at. Use the screen under the cursor, like the wheel does.

Small

Recent history is lost on quit, and the version is typed twice.History lives only in memory (Support.swift:232). "v0.1" is hard-coded in MenuPanel.swift:40 and in Info.plist; read it from the bundle instead so they never drift.

Shipping · free

GitHub, a landing page, one small download

No Apple Developer Program, no Homebrew. Friends download one small app, and only people who need the extra formats download more, from inside Chomp.

≈ 3 MB
Chomp.zip

The app itself. Today's binary is 1.1 MB. Does everything macOS can do on its own: photos, PDFs, documents, MP4/MOV/M4A.

≈ 20 MB
Extra formats pack

A trimmed ffmpeg, downloaded only when someone first picks WebP, MP3, WebM and so on. Rough estimate until it's built.

0
Things to install first

No Homebrew, no Terminal, no Xcode tools. The pack installs itself into Chomp's own folder.

The "built in" column is the goal, not today's code: right now every video and audio job calls ffmpeg. Moving the common ones to Apple's own video framework (AVFoundation) is the biggest coding job in this plan, and it's what lets most people never need the pack.

1. The repoFree
  • A public GitHub repo with an MIT licence. Public repos get free Mac build machines on GitHub Actions.
  • A workflow that, every time you tag a version, builds Chomp.zip and attaches it to a GitHub Release. You never upload by hand.
  • A second workflow builds the formats pack from ffmpeg's source with only the parts Chomp uses. It uses Apple's built-in H.264 encoder instead of x264, so the pack stays under the LGPL licence and Chomp can stay MIT.
  • The landing page lives in the same repo, in /docs, served free by GitHub Pages at yourname.github.io/chomp.
2. First openThe one annoying step

Without the paid Apple program, macOS blocks the first open of any downloaded app. Give friends two ways in and explain both on the landing page with pixel screenshots:

  • Download: unzip, drag to Applications, open it, click Done on the warning, then System Settings → Privacy & Security → "Open Anyway". Only once. On current macOS, right-click → Open no longer skips this.
  • One line in Terminal: downloads and installs it with no warning at all, because files fetched by curl aren't flagged the way browser downloads are. Only suggest this to people who trust you, and keep the script short and readable in the repo.
curl -fsSL https://yourname.github.io/chomp/install.sh | bash
3. The packInside the app
  • Slices that need the pack show a small lock. Dropping on one asks "Grab the extra formats? (about 20 MB)".
  • Chomp downloads the right file for the Mac's chip (Apple Silicon or Intel) from your GitHub Release, checks its fingerprint (SHA-256) so a broken or swapped file is refused, and saves it in Application Support.
  • No second warning: files Chomp downloads itself aren't flagged by macOS. The code already looks for a bundled ffmpeg in Support.swift, so this means one more place to look.
4. UpdatesFree
  • Once a day Chomp asks GitHub for the latest release. If it's newer, the menu bar panel shows "New version" with a download link.
  • Later, Sparkle can install updates by itself. It's free and uses its own signing key, not Apple's.
5. Landing pageGitHub Pages
  • Top: the animated chest, "Drag. Tap. Chomp.", and a big "Download for Mac · 3 MB" button that always points at the latest release.
  • Show it: a 10-second recording of drag → ⇧ → drop, then the three keys explained with the pixel icons.
  • First open: the steps above, with screenshots and the Terminal line.
  • Questions: "Why the warning?" (it's free and open source; Apple charges $99 a year to remove it), "Does it upload my files?" (no, everything happens on your Mac), macOS 13 or newer, Apple Silicon and Intel.
  • Check the name first: several apps are already called Chomp. A custom domain is optional, about $10–15 a year.
LaterIf it grows
  • The $99 Apple program removes the first-open warning. Nothing else in this plan changes.
  • A Homebrew cask, so people who use Homebrew can install it with one command.
  • Skip the Mac App Store. Its sandbox blocks the drag-anywhere trick and running ffmpeg.
